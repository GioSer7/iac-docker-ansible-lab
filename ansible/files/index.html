Laboratorio pratico di provisioning e configuration management locale.

Obiettivo del progetto

Questo server web Nginx è stato distribuito in modo completamente automatizzato. L'obiettivo è dimostrare la gestione dell'infrastruttura come codice tramite strumenti standard del settore Cloud & DevOps.

Architettura tecnologica

  • Sistema host Linux Mint
  • Provisioning Terraform (Docker provider)
  • Configuration Ansible Playbook
  • Runtime target Container Ubuntu 22.04
  • Web server Nginx
