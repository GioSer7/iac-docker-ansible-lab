# Politica di Sicurezza (Security Policy)

## Versioni Supportate

Questo progetto è un laboratorio didattico di Infrastructure as Code. Gli aggiornamenti e le migliorie vengono applicati esclusivamente al ramo principale.

- Ramo main: Supportato (Versione corrente)
- Altri branch: Non supportati

## Segnalazione di Vulnerabilità

Se riscontri una vulnerabilità di sicurezza (ad esempio una configurazione errata nei playbook Ansible o nei file Terraform):

1. Non aprire un'issue pubblica se il problema riguarda potenziali esposizioni di dati sensibili.
2. Segnala il problema aprendo una segnalazione riservata tramite la scheda "Security" della repository o contattandomi direttamente tramite l'email presente sul mio profilo GitHub.
3. Le segnalazioni verranno analizzate il prima possibile per applicare le dovute correzioni.
